repository. It was created by `ai-fleet init` from the react profile.

## Conventions

- Match the surrounding code's existing style, naming, and structure.
- Read at least three similar components before adding or changing one.
- Prefer the project's established state, data-fetching, and styling
  approach over introducing new libraries.

## Commands

- Discover build, test, lint, and dev commands from `package.json` scripts.

## Boundaries

- Never commit secrets. Treat `.env*` and credential files as read-only.
- Leave the working tree lint- and format-clean.
